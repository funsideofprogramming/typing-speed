# Typing Speed Test

A simple typing speed test built with C.

The program gives you a sentence to type, measures how long you take, and calculates your typing speed in words per minute (WPM) along with your accuracy.

## What it does

Displays a sentence for you to type

Measures the time taken to complete it

Calculates words per minute

Calculates typing accuracy

## Concepts used

String manipulation and character arrays

User input with `fgets()`

Time measurement with `gettimeofday()`

System calls and time structures

Functions and basic calculations

## How to run

Compile:

```bash
gcc main.c -o typingspeed
```

Run:

```bash
./typingspeed
```
